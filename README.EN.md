### Notes

1. <span id="ref1">Lyricify Lite will be renamed Lyricify Fusion. Because Lyricify 4 and Lyricify Lite have parallel positioning, and Lyricify Lite already includes many Lyricify 4 features, the name “Lite” can easily cause misunderstanding about its positioning. Therefore, starting from version 1.3.0, it will be renamed Lyricify Fusion.</span>
2. <span id="ref2">Lyricify Fusion supports all apps connected to SMTC, such as Spotify, Apple Music, Foobar 2000, HyPlayer, LyricEase, QQ Music, Netease Cloud Music UWP, Kugou Music and Groove Music.</span>
3. <span id="ref3">Lyricify 4 and Lyricify 3 can run on Linux and macOS through Wine. The setup process for Lyricify 4 may be cumbersome and requires patience.  <strong>For Linux:</strong> We are working on making Lyricify run through Wine on Linux as simply and reliably as possible. You can download the package from the <a href="https://github.com/Lyricify/Lyricify-on-Wine">Lyricify on Wine repository</a>.  <strong>For macOS:</strong> On Macs with Apple silicon, using a Windows on ARM virtual machine to run the Lyricify ARM64 version is recommended for a better experience. You can also use Crossover to run the x64 version (with a Windows 7 environment).</span>
4. <span id="ref4">Lyricify 3 has reached EOL, meaning that its lifecycle has ended. No new features, bug fixes or software updates will be released.</span>
5. <span id="ref5">Lyricify 3 currently supports Spotify, iTunes, Apple Music, Music Center, QQ Music, Netease Cloud Music and YesPlayMusic. Spotify users are advised to use Lyricify 4 instead of Lyricify 3.</span>

## Lyricify 4

### More than lyrics

A fantastic app that provides auto-scrolling lyrics and additional features for [Spotify](https://www.spotify.com).

**Please note: Lyricify 4 supports Spotify only!**

See the [Lyricify 4 User Guide](https://docs.lyricify.app/en/lyricify-4/).

Lyricify 4 is free software. Only some personalization settings are exclusive to the Store version. If you enjoy Lyricify 4, you can support the project in the following ways:

- Find the donation options in the app under Menu - About
- Purchase it from the [Microsoft Store](https://apps.microsoft.com/store/detail/9P4WB75RHWCH?launch=true&mode=full)

If you have difficulty purchasing Lyricify through the Microsoft Store, consider supporting it through a donation instead.

If you find someone selling this software illegally (the Lyricify version in the Microsoft Store is the only official release), please contact us. Thank you for your support!

## Lyricify Fusion

Lyricify Fusion, formerly Lyricify Lite, runs on Windows and provides Dynamic Lyrics Island, Desktop Lyrics, taskbar lyrics, Apple Music Lyrics and many other features. It supports music players connected to SMTC, including HyPlayer, LyricEase, Apple Music, QQ Music, Netease Cloud Music UWP, Kugou Music, Foobar 2000 and Groove Music.

See the [Lyricify Fusion User Guide](https://docs.lyricify.app/en/lyricify-lite/).

## Lyricify Mobile

Lyricify Mobile is the mobile member of the Lyricify family. It currently supports Android, iOS, iPadOS and visionOS, and a Windows version has also been released. macOS support is planned for a future version.

See the [Lyricify Mobile User Guide](https://docs.lyricify.app/en/lyricify-mobile/).

If you encounter incorrect lyrics in Lyricify Mobile, you can help improve them through Lyricify 4's lyric management.

## Lyricify 3

A fantastic app that provides auto-scrolling lyrics for [Spotify](https://www.spotify.com), [iTunes](https://music.apple.com), [Apple Music](https://music.apple.com), [Music Center](https://www.sony.com/electronics/support/articles/MC4PC020001), [QQ Music](https://y.qq.com), [Netease Cloud Music](https://music.163.com) and [YesPlayMusic](https://github.com/qier222/YesPlayMusic).

See the [Lyricify 3 User Guide](/docs/Lyricify%203/README.md).
